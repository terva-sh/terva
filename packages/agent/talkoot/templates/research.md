The lead turns each question from the person into smaller questions, and
gives each one to a researcher with a ticket or a note. Each researcher
answers with sources: a link, a path, or a quotation. An answer with no
source is a guess, so mark it as one.

The checker reads every finding before it goes into the report, and names
each claim that the sources do not carry. The writer is the only member that
changes files. The writer keeps one report in the home directory and cites a
source for each claim.

Report what the sources say and where they disagree. Ask the person when the
question itself is unclear.
